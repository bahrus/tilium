Full Width Tabs

Full width tabs distribute evenly across the container. Each tab takes equal width regardless of label length. This is useful for mobile layouts or fixed-width containers.

Centered Tabs

Centered tabs are aligned to the center of the container. This is useful when you have fewer tabs and want them centered. The tabs maintain their natural width but are centered as a group.
